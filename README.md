## About
Fantasy Game is an engaging desktop game combining classic fantasy elements with modern UI features. It offers players an immersive experience with rich graphics and persistent data storage.

## Features
- Admin panel to manage users and game settings
- Leaderboard to track top players
- Data persistence using MySQL database
- Built with C++ and Qt for cross-platform compatibility

## Technologies Used
- C++
- Qt Framework
- MySQL
- GitHub for version control
