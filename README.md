## Overview

Fantasy_Game is a fantasy football management application developed in C++ using the Qt framework.  
It simulates football clubs, leagues, matches, and player management with a rich UI and SQL backend.

---

## Features

- Manage football clubs and players  
- Create and simulate matches and leagues  
- User login and signup system  
- Interactive GUI with Qt Widgets  
- Persistent data storage using SQL database
